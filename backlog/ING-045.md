### [ING-045] Frontend: "change location" city search saving via `PUT /api/weather/location`

**As a** wardrobe owner
**I want** to search for a city and pick it as my weather location
**So that** the weather panel shows weather where I actually am

**Acceptance criteria** (Gherkin):
```
Given the weather panel is shown
When the user activates "change location" and submits search text
Then the UI calls GET /api/weather/cities?q=<text> (URL-encoded) and lists each
  result as name with admin1 and country

Given the search returns []
When results render
Then the UI shows a "no cities found" message

Given the search text is empty or whitespace-only
When the user submits
Then no request is sent (the backend would answer 400)

Given the search returns 502 or fails
When results render
Then the UI shows an error and the current location stays unchanged

Given a list of results
When the user picks one
Then the UI PUTs /api/weather/location with {name, country, latitude, longitude}
  of that result (admin1 is not sent)
And on success the panel reloads GET /api/weather and shows the new location

Given the PUT returns 400
When the response arrives
Then the server's error message (naming the field) is shown and the panel
  keeps the previous location

Given the user cancels the search
When it closes
Then no PUT is sent and the panel is unchanged
```
