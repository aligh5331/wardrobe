## Implementation notes

**Scope decision (Ali, this session).** ING-024's Tester/Reviewer found that the
structural suite asserted three things `frontend/src/App.test.jsx` did **not**

Ali chose **port the three assertions into Vitest, then delete**. That is why
this scoped "test-only" ticket also touches `frontend/src/App.test.jsx`: per
`agents/tester.md`, `frontend/src/**` is Tester-denied, so porting it is
Coder work. The ticket's literal AC ("no replacement test is added") refers to
a replacement *structural/source-grep* suite; the additions are rendered-DOM
tests in the existing Vitest suite, so they are not a second structural suite.

**Files changed**
- `tests/frontend/ing_020_app_test.mjs` — **deleted** (145 lines). The
  superseded structural suite.
- `frontend/src/App.test.jsx` — added three rendered-DOM tests (48 lines
  added, no existing test changed).

**What the new tests cover (the ported delta)**
- **Fetch-error path.** `it.each` over (i) a non-OK HTTP response
  (`stubFetch([], { ok: false, status: 500 })`) and (ii) a network rejection
  (`vi.fn().mockRejectedValue`). Both assert the "Could not load the catalog."
  error text renders, no `listitem` cards exist, and the empty-catalog text is
  absent — so an error cannot be mistaken for an empty catalog.
- **Non-array 2xx body.** `stubFetch({ not: 'an array' })` asserts the app
  falls back to the empty state (exact empty-state text present, no cards, no
  error) rather than throwing in `items.map`.
- **Read-only guard.** Renders one item, then asserts `fetch` was called
  exactly once with the bare `/api/items` URL (no `RequestInit`, so no
  method/POST/PUT/DELETE/PATCH) and that the rendered subtree contains no
  `button, form, input, select, textarea` — the DOM equivalent of the old
  source-grep assertions.

**Files changed notes**
- No source drift: the only reference to the deleted file left anywhere under
  `tests/` or `frontend/` was intentionally removed. `grep` for
  `ing_020_app_test` under both trees returns no matches. (A provenance comment
  initially named the path; reworded so no file under `tests/`/`frontend/`
  references it, per AC1.)
- The deleted file defined no exported helpers — only file-local bindings — so
  there was no helper symbol to chase.

**Assumptions / decisions for Tester + Reviewer**
