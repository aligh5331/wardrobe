### [ING-050] Frontend: recommendation panel

**As a** wardrobe owner
**I want** a "Suggest outfits" panel with formality and a note
**So that** I can ask for today's outfits and see them as garment photos

**Acceptance criteria** (Gherkin):
```
Given the app loads
When it renders
Then a recommendation panel shows under the weather panel with a formality select
  (any, casual, smart-casual, formal), a note text box, and a "Suggest outfits" button
And POST /api/recommendations is NOT called on load

Given the user picks "formal", types "wedding", and clicks "Suggest outfits"
When the request is sent
Then it POSTs /api/recommendations with {"formality":"formal","note":"wedding"}
And with "any" selected and an empty note, the body omits formality and note (or sends them empty)

Given a request is in flight
When the panel renders
Then the button is disabled and a loading message shows

Given a 200 response with 3 outfits
When it renders
Then 3 outfit rows show, each with one photo per item (in response order) and the reason
And an item photo that fails to load shows the same placeholder the catalog grid uses

Given a 400, 422, or 502 response with {"error": "..."}
When it renders
Then that server message is shown, and the weather panel and catalog grid are unchanged

Given the request fails with no response (network error)
When it renders
Then a generic error message is shown, and weather panel and catalog are unchanged

Given results are shown and the user clicks "Suggest outfits" again
When the new response arrives
Then the new outfits replace the old ones
```

**Spec reference:** `07-architecture.md` "Recommender (Phase 3)" (UI paragraph,
request body, response shape, error table); `06-decisions.md` "Testing tooling"
